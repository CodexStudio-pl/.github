# CodexStudio

**CodexStudio** to polski software house specjalizujący się w tworzeniu nowoczesnych stron internetowych, botów Discord oraz rozwiązań dopasowanych do potrzeb klientów.<br>
Stawiamy na funkcjonalność, estetykę i indywidualne podejście do każdego projektu.

## 🛠️ Nasze usługi
- 🌐 **Strony internetowe** - landing page, strony firmowe i dedykowane aplikacje webowe.
- 🤖 **Boty Discord** - automatyzacja, systemy ticketów, integracje i rozwiązania dopasowane do serwerów.
- ✈️ **Boty Telegram** - automatyzacja i funkcjonalności dopasowane do potrzeb użytkowników.
